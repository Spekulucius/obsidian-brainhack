## Callouts

All of Obsidian's callout types come restyled: a soft tinted background, a colored outline and a dashed title separator.

Brainhack also ships a few custom callouts of its own:

| Callout          | What it does                                                       |
| :--------------- | :----------------------------------------------------------------- |
| `> [!brainhack]` | Styled with your accent color                                      |
| `> [!1]`         | A minimal callout without an icon                                  |
| `> [!2]`         | Lays its content out in even, responsive columns                   |
| `> [!!]`         | Draws an accent-colored ring around the callout to make it pop     |

## Headings

Headings come in three flavors, switchable in Style Settings:

- **default** – clean, colored text
- **Variant 1** – headings become badges with a background
- **Variant 2** – a simple underline

Each heading level (H1–H6) can additionally get its own color via the color pickers in Style Settings.

## Colored folders

Turn on `Colored Folders` to color folder names in the file navigator by nesting depth – four levels, each with its own color picker. `Enhanced Folders` additionally highlights the folder you currently have open.

## Style Settings overview

Everything you can adjust, in one place:

| Section          | Options                                                                                          |
| :--------------- | :----------------------------------------------------------------------------------------------- |
| Text and Spacing | Font weight, letter spacing and line spacing sliders                                              |
| Headings         | Heading variant, per-level heading colors                                                         |
| Blockquotes      | Blockquote variant                                                                                |
| Callouts         | Callout variant                                                                                   |
| Canvas           | Colored canvas nodes                                                                              |
| Background       | Background saturation and brightness sliders                                                      |
| Folders          | Colored folders with four level colors                                                            |
| Experimental     | Workspace corner radius, hide status bar, greyscale images, enhanced folders, hide scrollbars, smart lists (WIP) |

## Little extras

- **Greyscale images** – a toggle that desaturates images and blends them into light or dark mode
- **Hide status bar** – the status bar fades out and only appears when you hover over it
- **Colored canvas nodes** – canvas cards can take on their assigned color as background
- **Hidden attachment folder** – folders ending in `000_attachments_000` are hidden from the file navigator to keep it clean
